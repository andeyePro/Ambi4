# Ambi4.work
## Ambience for Work
### Coming soon
Customisable endless music generated just for you, to help you work
### Available now
A growing list of work-optimised music playlists.
Apple Music now, Spotify and perhaps others to follow.

## Get involved
1. Install Node.js 20+
2. Fork this
3. `npm install` then `npm run dev` to open your local development server
4. See changes you make live in your local development server
5. Send a pull request

## Adding a playlist
Add a markdown file under `src/content/playlists/[section]/` with `title`, `date`, `playlist` (the Apple Music embed path, e.g. `ambi4-work-ambient-eno/pl.u-...`) and optional `thumbnail` frontmatter; the page body is the description.
